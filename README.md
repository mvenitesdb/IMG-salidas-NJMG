# IMG salidas NJMG

Generador de imágenes (9:16) para las salidas congregacionales del grupo Norte Gutiérrez.
Se abre `index.html` en el navegador (computadora o celular), se cargan los datos y se comparte la imagen.

## Versiones

- **v2** (actual, `index.html`): 12 paletas y color personalizado; varios horarios el mismo día; si hay mucho contenido genera varias imágenes automáticamente.
- **v1** (`versiones/v1.html`): primera versión. Un diseño base, 5 paletas, salidas y avisos ilimitados en una sola imagen.

Cada versión nueva se guarda como `versiones/vN.html`, y `index.html` siempre es la última.
